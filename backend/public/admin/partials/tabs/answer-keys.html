Nạp bộ đáp án

Dán bộ đáp án của một mã đề vào đây rồi đối chiếu với đáp án đang lưu trong ngân hàng câu hỏi. Chỉ có ảnh bảng đáp án? Copy prompt bên dưới, dán vào chat AI kèm ảnh, rồi mang JSON nó trả về dán lại — server không tốn đồng token nào. Nạp nhiều lần cho cùng mã đề sẽ cộng dồn.
Chỉ có ảnh? Gửi ảnh + prompt này vào DeepSeek/ChatGPT/Gemini, rồi dán JSON nó trả về xuống dưới.
