Thêm câu đơn (Part 1·2·5)

Mỗi màn đúng 1 câu: Part 1 (mô tả tranh) · Part 2 (hỏi–đáp) · Part 5 (hoàn thành câu). Part 3·4·6·7 dùng tab Nhóm câu.

Dán 1 object hoặc mảng MÀN HỎI. Bí thì bấm Copy prompt rồi đưa cho AI.

Điền Source → prompt copy ra sẽ ép AI dùng đúng mã đề đó cho mọi câu. Dán prompt vào ChatGPT/AI → lấy mảng JSON → dán xuống dưới.

Part 1 (ảnh) / Part 2 (audio): path trong JSON phải trỏ file đã có sẵn trên server. Nếu file chưa có, hãy dùng tab “Nhập tay” (upload trực tiếp) thay vì dán path tay. Part 5 không cần media.

Part 3/4/6/7 là màn nhiều câu — tạo ở tab Nhóm câu.
Số hiển thị lúc làm bài — phải khớp số ghi trong ảnh đề (P1 1–6, P2 7–31, P5 101–130).
