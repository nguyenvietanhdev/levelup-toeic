# LevelUp TOEIC — Project Documentation

## Overview

Ứng dụng học TOEIC fullstack gồm backend Node/Express và frontend (Vite) với nhiều tính năng: quản lý người dùng, bài tập, từ vựng, test TOEIC, TTS, AI endpoints, gamification.

## Repo layout (high level)

- backend/: Node.js server, routes, controllers, models, middleware
- frontend/: Vite app, `src/` contains UI
- docs/: project documentation (this file)

## Backend

- Start scripts (see backend/package.json):
  - `npm run dev` — starts with `nodemon server.js`
  - `npm run start` — `node server.js`
  - other dev variants: `dev1`, `dev2`
- Key folders:
  - `config/` — DB, OpenAI, Redis, swagger setup
  - `controllers/` — request handlers
  - `models/` — Mongoose schemas
  - `routes/` — route definitions
  - `middleware/` — auth, error handling, file upload, cache
  - `queues/` — background jobs (BullMQ)

## Setup & Run (local)

1. Install deps for backend and frontend:

```bash
cd backend
npm install
# in another terminal
cd frontend
npm install
```

2. Run backend (development):

```bash
cd backend
npm run dev
```

3. Run frontend (development):

```bash
cd frontend
npm run dev
```
